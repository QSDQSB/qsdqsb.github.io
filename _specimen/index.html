It is not for readers. `_specimen/` is built only by the seeded visual build (`npm run visual:build`, which includes it through `_config_visual.yml`); the live build never reads it. A state a pointer or a key would bring is drawn at rest with a class (.is-lit, .is-focus, .is-pressed), through the piece's own state mixin, so the page shows what the piece does.

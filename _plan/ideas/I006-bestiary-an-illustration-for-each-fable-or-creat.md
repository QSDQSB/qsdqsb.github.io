## Verdict

## Made explicit

Not one picture, nor vector art as such: a language that every fable's art is made in, so the
Bestiary reads as one book however many fables it holds. The lead's draft, with the three references
set in the built pages: [the study](../studies/2026-11-24-bestiary-plates.md). Quiver's API (text to
SVG) was found and not used; it needs a key, and the study's medium is not vector.

{% comment %} What's New — the four most recently modified documents across Posts, Portfolio and Voyage. jekyll-last-modified-at gives each doc a git-based `last_modified_at`, but it is a Determinator object that Liquid's `sort` cannot order. So we encode a fixed-width sortable timestamp + the doc's index into one token per doc, sort the tokens as strings (14-digit prefix ⇒ chronological), reverse for newest-first, and map back to the document. Pure Liquid — works under GitHub Pages safe mode. Layout: 1 feature + 2 stacked + 1 wide (3:1). {% endcomment %} {% assign combined = site.posts | concat: site.portfolio | concat: site.voyage %} {% assign keyed = "" %} {% for d in combined %}{% assign k = d.last_modified_at | date: "%Y%m%d%H%M%S" %}{% assign keyed = keyed | append: k | append: "#" | append: forloop.index0 | append: "|" %}{% endfor %} {% assign ordered = keyed | split: "|" | sort | reverse %}
